Рекомендации по дальнейшему развитию python_trainer

1. Текущая рабочая версия состоит из файлов с суффиксом 2. После проверки замените ими исходные файлы или переименуйте их, чтобы приложение запускалось как `streamlit run src/app2.py`.
2. Перед запуском установите зависимости из requirements.txt и задайте переменную окружения OPENAI_API_KEY. Ключ не следует хранить в исходном коде или коммитить в Git.
3. В текущем прототипе запуск кода через exec выполняется в процессе Streamlit и не является безопасным sandbox. Не запускайте недоверенный код. Для публичного сервиса понадобится изолированный контейнер/процесс с ограничением времени, памяти, файловой системы и сети.
4. Сейчас в приложении есть одна встроенная задача. Следующим шагом можно вынести список задач в отдельный JSON/YAML-файл и добавлять выбор темы и сложности.
5. Полезно сохранять не только задачи, но и попытки ученика, результаты запуска, ответ преподавателя и количество попыток.
6. Для надёжности стоит добавить тесты для run_code и history_manager, включая пустую историю, повторное сохранение и ошибочный код.
7. Для генерации задач через API можно добавить отдельную кнопку «Новая задача» и сохранять ответ API в структуру title/topic/description, а не только как текст.
8. Для production-режима добавьте обработку лимитов API, сетевых ошибок и понятное отображение стоимости/ограничений запросов.
9. Путь к данным уже привязан к корню проекта через pathlib, поэтому приложение не зависит от текущей рабочей директории.
10. После отладки рекомендуется убрать дублирующиеся исходные файлы без суффикса 2 и оставить один согласованный набор модулей.
